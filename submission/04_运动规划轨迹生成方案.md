# 机器人动作规划轨迹生成方案（hierarchical_cuRobo_planner）

> 本资料为 mt-embodied-sim 预赛提交的补充技术文档，说明平台如何使用自研
> `hierarchical_cuRobo_planner` 为家庭 5S / 隐形家务任务生成机器人动作规划轨迹。
> 代码库：`D:\githbi\hierarchical_cuRobo_planner`

---

## 1. 在平台中的定位

隐形家务任务（抓取归位、台面擦拭、橱柜归整等）的仿真训练，首先需要**无碰撞、动力学可行的参考轨迹**：
作为模仿学习的专家示教、强化学习的奖励塑形基准，以及 Sim2Real 部署前的动作可行性校验依据。

mt-embodied-sim 采用自研的 **CUDA/MUSA 原生分层运动规划库** `hierarchical_cuRobo_planner`
（PyTorch + cuRobo 为核心），与平台的 Backend 抽象层同源设计，可在 NVIDIA CUDA 与
摩尔线程 MUSA 两种算力后端上运行，补齐了"场景重建 → 轨迹规划 → 数据合成 → 模型训练"链路中的
**动作生成**环节。

## 2. 分层规划架构

| 层级 | 算法 | 空间 | 作用 |
|---|---|---|---|
| 高层 | GPU A* | 3D 任务空间 | 在体素占据栅格上生成粗略末端执行器路径，避开家具等大障碍，保证全局拓扑可行性 |
| 中层 | cuRobo 批量 IK | 关节空间 | 并行反解每个路径点的关节配置（多种子、位置/姿态双阈值） |
| 低层 | cuRobo 轨迹优化 | 关节空间 | L-BFGS 平滑为动力学可行轨迹，处理自碰撞与关节限位 |

- **GPU 原生数据流**：A*、几何工具、碰撞校验、IK/TO 全部围绕 torch 张量实现，减少 CPU-GPU 搬运；
- **后端抽象**：`backend.py` 自动检测 CUDA / MUSA，MUSA 环境下世界碰撞回退为 PyTorch 张量距离检测，
  并在 TrajOpt 后追加 collision-penalty refiner 主动避障；
- **长程扩展**：`LongHorizonPlanner` + 可插拔 `SubgoalPlanner`（启发式 / 扩散-EBM），
  把单点规划扩展为"接近 → 抓取 → 搬运 → 放置"的多子目标长程任务轨迹；
- **工程化**：YAML 配置驱动、CLI 入口、轨迹校验（FK 一致性 / 关节限位 / 速度/加速度/加加速度批量 GPU 检查）、
  pytest 覆盖、pyproject 打包。

## 4. 复现方法

```bash
# 家居台面场景 A* 轨迹（本提交附件，CPU 即可运行）
.venv/Scripts/python.exe submission/attachments/trajectories/generate_home_trajectory.py

# 完整分层管线（需 CUDA/MUSA + cuRobo）
cd D:\githbi\hierarchical_cuRobo_planner
pip install -e .
curobo-hierarchical-plan plan config/franka_example.yaml \
  --start "0,0,0,0,0,0,0" --goal "0.5,0.2,0.4" -o plan_result.npz

# 长程任务（多子目标拼接，如"接近→抓取→搬运"）
curobo-hierarchical-plan longhorizon-plan config/longhorizon_example.yaml \
  --start "0,0,0,0,0,0,0" --planner heuristic -o longhorizon_result.npz
```

## 5. 与 mt-embodied-sim 任务工坊的衔接

1. **任务定义 → 规划请求**：任务工坊中每个隐形家务任务（抓取归位、抽屉收纳、台面擦拭…）
   解析出 start/goal 位姿与场景占据栅格，构造 `PlanRequest` / `LongHorizonRequest`；
2. **轨迹生成**：分层规划器输出关节空间平滑轨迹，经 `TrajectoryValidator` 校验
   （FK 误差、限位、速度/加速度/加加速度）；
3. **数据合成**：可行轨迹驱动仿真执行，同步录制 RGB-D / 点云 / 关节状态多模态数据，
   作为 VLA/WAM/BFM 模型的专家示教；
4. **Sim2Real 校验**：PACE 式执行器动力学标定模块（`system_identification/`）从真机日志
   辨识关节动力学参数，预测真机跟随规划轨迹的跟踪误差与峰值力矩，实现"动力学可行"判断。
